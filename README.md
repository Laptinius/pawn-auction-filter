# Pawn Auction Filter

By Laptinius.

An addon for WoW Forever 1.60.1. On the **Buy** tab, choose a category and level range, run a search, then click **↑ Pawn** next to the filter menu. The list shows gear that Pawn marks as an upgrade for at least one of your character's enabled scales. The Pawn label turns green when the filter is on. Click again to restore the full list.

## Installation

1. Install Pawn for WoW Forever and enable the scales you want to use.
2. Extract the `PawnAuctionFilter` folder into `_forever_/Interface/AddOns/`. The `PawnAuctionFilter.toc` file belongs directly inside the `PawnAuctionFilter` folder.
3. If the game is running, type `/reload` in chat. If the addon does not appear in the list, restart the game.
